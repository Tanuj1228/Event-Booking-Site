# 🎟️ EventEase – Real-Time Event Ticket Booking System

EventEase is a scalable, full-stack web application designed for **real-time event ticket booking and seat management**.  
It ensures **conflict-free seat allocation** using concurrency control mechanisms and provides a seamless experience for both users and event organizers.

---

## 🚀 Key Highlights

- ⚡ Real-time seat updates using WebSockets (Socket.IO)
- 🔒 Secure authentication with JWT & bcrypt
- 🧠 Concurrency handling using Redis (prevents double booking)
- 🛠️ Admin dashboard for event management
- 📊 Modular and scalable backend architecture

---

## 🧩 Features

### 👤 User Features
- Browse available events
- Interactive seat selection UI
- Real-time seat availability updates
- Secure ticket booking
- View booking history

### 🛠️ Admin Features
- Create, update, and delete events
- Define seat layouts and pricing
- Monitor bookings and users

### ⚙️ System Features
- Role-Based Access Control (RBAC)
- Real-time synchronization across users
- Atomic seat locking using Redis
- RESTful API architecture
